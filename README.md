# Sample Data for Data Preparation Toolkits

This repository contains the sample datasets for test-driving the toolkits developed and described in our research work: 
*Systematizing Data Preparation in Smart Manufacturing via Axiomatic Design: A Toolkit Integrating GUI and Agentic AI* ([DOI: 10.21203/rs.3.rs-8872511/v1](https://doi.org/10.21203/rs.3.rs-8872511/v1)). 

To browse and download the datasets via a standalone interface, please visit **[Sample Data Download Portal](https://commons-repo.github.io/003-sample-data/)**.
